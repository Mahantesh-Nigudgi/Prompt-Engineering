01 / NumPy

the array engine underneath everything

NumPy (Numerical Python) gives Python a fast, fixed-type array — the ndarray — plus the vectorized math to operate on it without writing loops. Pandas, Matplotlib, Seaborn and most of the machine learning stack are all built on top of it, so it's genuinely the foundation, not just "another library."

Core concepts

The ndarray

NumPy's core object is the n-dimensional array. Unlike a Python list, every element shares one dtype, which is what lets NumPy store data compactly and run operations in fast, compiled C code instead of the Python interpreter. Almost everything else in the library builds on this one structure.

Array creation

You rarely type arrays out by hand. np.arange() builds a range, np.linspace() spaces values evenly between two numbers, and np.zeros()/np.ones()/np.full() pre-allocate arrays of a given shape. np.random generates arrays for simulations and test data.

Indexing & slicing

Arrays support the same a[start:stop:step] slicing as lists, extended to multiple dimensions with commas: a[1:3, :2]. Boolean indexing (a[a > 0]) and fancy indexing (a[[0,2,4]]) let you filter and reorder data without writing a single loop.

Broadcasting

Broadcasting is the rule set that lets NumPy combine arrays of different shapes, like adding a single row to every row of a matrix, by "stretching" the smaller array without actually copying memory. It's the single idea that makes NumPy code short instead of loop-heavy.

Vectorization & ufuncs

Universal functions (np.sqrt, np.exp, +, *...) apply element-wise across an entire array in one call. Writing a + b instead of looping over both arrays is what gives NumPy its speed, often 10-100x faster than plain Python for numeric work.

Reshaping & axes

Every array has a shape describing its dimensions, and reshape() lets you rearrange the same data into a new one, e.g. a flat list of 12 numbers into a 3×4 grid. Most aggregate methods accept an axis argument to control whether you're summarizing rows or columns.

02 / Pandas

spreadsheets, but programmable

Pandas wraps NumPy arrays with labeled rows and columns, giving you the Series and DataFrame — structures built specifically for messy, real-world tabular data. It's the tool you reach for the moment your data has column names, missing values, or needs grouping and filtering.

Core concepts

Series vs DataFrame

A Series is a single labeled column of data — values plus an index. A DataFrame is a table made of several Series that share the same index, essentially a spreadsheet you can script. Most work starts by loading data straight into a DataFrame.

Reading & writing data

pd.read_csv(), read_excel() and read_json() turn files straight into DataFrames, and their .to_csv()/.to_excel() counterparts write them back out. This is usually the first and last line of any pandas script.

Selecting data

.loc[] selects by label (row/column names), while .iloc[] selects by integer position, mirroring NumPy. Boolean masks like df[df.age > 30] filter rows by condition, the pandas equivalent of a SQL WHERE clause.

Handling missing data

Real data has gaps. .isna() flags missing values, .dropna() removes rows or columns containing them, and .fillna() substitutes a default or interpolated value so downstream math and models don't break.

GroupBy & aggregation

.groupby() implements the "split-apply-combine" pattern: split rows into groups by a column's value, apply an aggregate like .mean() or .sum() to each group, then combine the results — the same idea as a pivot table.

Merging & joining

pd.merge() combines two DataFrames on a shared key column, the same logic as a SQL join, while pd.concat() stacks DataFrames on top of or beside each other. Both are essential once your data lives in more than one table.

Properties & methods you'll actually use

03 / Matplotlib

the original Python plotting library

Matplotlib turns arrays and DataFrames into figures — line charts, bar charts, scatter plots, histograms and more. It's low-level and highly customizable, which is exactly why higher-level libraries like Seaborn and pandas' own .plot() are built directly on top of it.

Core concepts

Figure & Axes anatomy

A Figure is the entire canvas or window; an Axes is one individual plot living inside it — a figure can hold several axes as subplots. Understanding this split is the key to everything else in matplotlib, especially multi-panel charts.

pyplot vs object-oriented API

The quick plt.plot() style implicitly tracks a "current" figure and axes — great for one-off charts. The object-oriented style (fig, ax = plt.subplots()) gives you explicit handles to work with, which scales far better for anything with multiple subplots.

Plot types

plot() draws lines for trends over time, bar() compares categories, scatter() reveals relationships between two variables, and hist() shows a single variable's distribution. Choosing the right plot type is half the job of visualizing data well.

Customizing a chart

Titles, axis labels, legends, colors, line styles and gridlines all have dedicated methods (set_title(), legend(), etc.). A chart without labels is barely more useful than raw numbers, so this step is never optional in real work.

Subplots & layouts

plt.subplots(rows, cols) creates a grid of axes in one call, letting you compare several charts side by side — think a dashboard with revenue, users, and errors all on one screen.

Saving & exporting

fig.savefig('chart.png', dpi=300) exports a chart as an image file for a report, slide deck, or publication, and supports vector formats like SVG and PDF for print-quality figures.

Properties & methods you'll actually use

04 / Seaborn

statistical plots, styled by default

Seaborn sits on top of Matplotlib and works directly with Pandas DataFrames, trading manual control for beautiful defaults and built-in statistics. What takes ten lines of matplotlib setup — themes, color palettes, confidence intervals — often takes one line in seaborn.

Core concepts

Seaborn & Matplotlib

Seaborn doesn't replace matplotlib, it wraps it — every seaborn plot returns a matplotlib Axes you can still customize with plt or ax calls. Think of seaborn as the "statistics and styling" layer over matplotlib's "drawing" layer.

Themes & palettes

sns.set_theme() switches the overall look (grid, fonts, colors) in one call, and named color palettes like 'deep' or 'coolwarm' keep multi-category charts readable and consistent without manual color picking.

Relational plots

scatterplot() and lineplot() show the relationship between two numeric variables, and can automatically color or size points by a third category (hue, size) — a task that takes real effort in raw matplotlib.

Categorical plots

boxplot(), violinplot() and barplot() compare a numeric variable across categories, automatically computing summary statistics like medians, quartiles, and confidence intervals as part of the plot itself.

Distribution plots

histplot() and kdeplot() visualize how a single variable is distributed, with an optional smooth density curve layered over the histogram bars in one function call.

Matrix & grid plots

heatmap() visualizes a matrix of values (like a correlation table) as color intensity, and pairplot()/FacetGrid automatically lay out a grid of small charts, one per variable or category combination.

Properties & methods you'll actually use

Property / MethodWhat it does
sns.set_theme()Applies a consistent visual style and color palette to all following plots.
sns.scatterplot()Plots two numeric variables against each other, optionally colored by a category.
sns.lineplot()Plots a trend over an ordered variable, with an automatic confidence band.
sns.boxplot() / violinplot()Summarizes a numeric variable's spread across categories.
sns.histplot() / kdeplot()Visualizes the distribution (and density) of a single variable.
sns.heatmap()Renders a 2-D matrix, such as a correlation table, as a grid of colored cells.
sns.pairplot()Builds a grid of scatter plots for every pair of numeric columns in one call.
sns.barplot()Compares an aggregate (like a mean) of a numeric variable across categories.

More ways to visualize this

sns.boxplot()

The box marks the middle 50% of values, the orange line is the median, and the whiskers show the full range — one sns.boxplot() call summarizes an entire distribution per species. (Illustrative values.)

sns.scatterplot(hue=...)

Adding hue='species' to a plain scatter plot colors each cluster automatically — no manual color mapping needed, unlike raw matplotlib.

sns.lineplot() + CI band

The shaded band is a 95% confidence interval computed automatically by sns.lineplot() — plain matplotlib would need several extra lines of code to draw it manually.

sns.violinplot()

A violin plot is a box plot's shape rounded out into a full density curve — wider sections mean more values sit at that height, so you see the distribution's shape, not just its quartiles.

sns.histplot(kde=True)

Bars show the raw tips dataset counts; the smooth orange curve is the kernel density estimate — both come from one sns.histplot(data, kde=True) call.

sns.barplot()

sns.barplot() plots the mean rating per day and draws the error bars for you, showing both the estimate and its uncertainty in one call.

sns.pairplot()

One sns.pairplot(df) call builds this whole grid automatically: a distribution on the diagonal for each variable, and a scatter plot for every pair — the fastest first look at a new dataset.

RW

Real-world example: exploratory data analysis (EDA)

Before training any machine learning model, data scientists run EDA to understand their features — seaborn's pairplot() and heatmap() are the fastest way to spot which variables actually predict the target and which ones are redundant, directly shaping feature selection decisions.
